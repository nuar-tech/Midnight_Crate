MIDNIGHT CRATE — ПОДГОТОВКА К ЗАЩИТЕ

На каждого: 1,5 минуты показать функции + 30 секунд отвечать по коду.
До защиты открыть сайт и VS Code. Это фронтенд-демонстрация, реальные заказы не отправляются.

Аида: Order
1. Добавь Deadline Desk (2 900 ₸), выбери D3 (500 ₸): итог 3 400 ₸.
2. Нажми Confirm с пустыми полями: ошибки под каждым полем.
3. Покажи неверный телефон и дневное время, затем исправь. Ошибки исчезают.
4. Заполни валидно и подтверди: сообщение, очищенная форма и пустая корзина.
5. Покажи мобильную ширину и FAQ.

Код, который надо понимать:
products — массив 8 объектов, каждый имеет id, name, category, price, description, image.
renderCatalog: filter по категории/поиску, sort по цене/названию, createElement и append для карточек.
cart — объект {id: количество}. subtotal использует reduce для суммы price * quantity.
renderCart синхронизирует счётчик, модальное окно и чек. Доставка зависит от выбранного общежития.
validators — функции проверок. touched хранит поля, которые уже редактировались; ошибки не показываются при открытии.
submit: preventDefault останавливает обычную отправку; validateField проверяет; success выводится через textContent; form.reset очищает поля.
localStorage сохраняет только корзину. Контакты остаются в текущем документе. try/catch даёт работу без storage.
.stop(true,true) завершает старую анимацию и очищает очередь при быстрых кликах.
jQuery slideDown/slideUp — FAQ, fadeIn/fadeOut — уведомления, animate — плавная прокрутка.
CSS @media перестраивает колонки; prefers-reduced-motion отключает движение.
